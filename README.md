# phone-pay-dashboard
📊 PhonePe Transaction Analytics Dashboard
🚀 End-to-End Data Analytics Project using Power BI

This project demonstrates an end-to-end data analytics workflow using Kaggle data, from data preparation and transformation to data modeling, DAX calculations, visualization, and business insights.

The objective was to transform raw transaction data into an interactive Power BI dashboard that provides a clear view of transaction performance, users, payment status, services, age segments, and monthly trends.

🛠️ Tools & Technologies
Power BI – Dashboard development & interactive visualization
Power Query – Data cleaning, transformation & preparation
DAX – Calculated measures, KPIs & analytical calculations
Excel – Initial data handling and validation
CSV – Structured dataset used for analysis
Kaggle – Source of the raw dataset

🧹 Data Preparation & Power Query

I used Power Query to prepare the raw dataset before building the dashboard.

The data preparation process included:

Imported raw Kaggle data
Converted/prepared the dataset into CSV format
Removed duplicate records
Handled missing/null values
Corrected data types
Standardized date/month fields
Cleaned categorical fields
Prepared transaction and user-related fields for analysis
Created a structured dataset suitable for Power BI

This ensured that the data was consistent and ready for analysis before creating visualizations.

📐 DAX & KPI Development

I used DAX (Data Analysis Expressions) to create calculated measures and KPIs for the dashboard.

Total Transactions

Successful Transactions
Transaction analysis by:

📊 Dashboard Features
1️⃣ Transaction Performance

Analyzed monthly transaction value to identify:

Monthly fluctuations
High and low transaction periods
Overall transaction trends
2️⃣ Transaction Value by User

Created a comparison of transaction value across individual users to identify high-value transaction contributors.

3️⃣ Weekday vs Weekend Analysis

Analyzed transaction distribution between:

Weekdays
Weekends

This helps understand transaction behavior across different parts of the week.

4️⃣ Service-Level Analysis

Compared transaction value across services such as:

Loans
Money Transfer
Insurance
Recharge Bills

This provides visibility into which services contribute more to overall transaction value.

5️⃣ Payment Status Analysis

Analyzed monthly transactions based on payment status:

Successful
Failed
Pending

This helps monitor transaction reliability and identify periods with unusual payment behavior.

6️⃣ User Age-Segment Analysis

Created customer segmentation using:

Gen X
Millennials
Gen Z
Boomers

This allows transaction/user behavior to be examined across different age groups.

7️⃣ Success Rate KPI

Created a dedicated KPI showing the overall transaction success rate.

Overall Success Rate: 96.15%
